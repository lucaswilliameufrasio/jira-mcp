# Project Skills

These project-local skills are vendored from the team's reusable engineering
guidance so contributors and coding agents can work without installing anything
from a package marketplace.

| Skill | Use when |
|---|---|
| `integration-testing` | Adding or changing tests, handlers, clients, Docker infrastructure, or CI. |
| `quality-gate` | Verifying a change before calling it complete or committing it. |
| `secrets-safety` | Handling OAuth, Jira, Valkey, or any other credentials. |
| `document-decisions` | Making a non-trivial architecture or integration decision. |

The repository does not require `npx skills` or network access to load these
guidelines.
