# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
The short version:

- Be respectful and constructive in issues, pull requests, and discussions.
- Assume good faith; disagree with ideas, not people.
- No harassment, discrimination, trolling, or personal attacks.
- Keep discussions on topic; critique code, not people.

Project maintainers may remove, edit, or reject comments, commits, pull
requests, and issues that violate this code. Repeated violations lead to a
permanent ban from project spaces.

Instances of abusive or unacceptable behavior can be reported privately
through [GitHub private vulnerability reporting](https://github.com/lucaswilliameufrasio/jira-mcp/security/advisories/new)
or directly to the repository owner. All reports are reviewed and kept
confidential.

This Code of Conduct is adapted from the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
